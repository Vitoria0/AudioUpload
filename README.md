# Audio File Upload & Playback

Este projeto permite o envio e a reprodução de arquivos de áudio, oferecendo uma interface simples e moderna para o upload  de arquivos.

## Funcionalidades

- **Upload de Arquivos**: Permite o envio de arquivos de áudio para o servidor.
- **Exibição de Arquivos Enviados**: Lista os arquivos de áudio já enviados, permitindo selecionar e escutá-los.

## Tecnologias Utilizadas

- **Frontend**: 
  - **Vue.js**: Framework JavaScript para criar a interface do usuário.
  - **Vite**: Ferramenta de build e bundler rápida para Vue.js.
  - **HTML5 Audio API**: Para reprodução de áudio no navegador.
  
- **Backend**:
  - **Flask (Python)**: Framework web leve para a criação da API que lida com o upload e armazenamento de arquivos de áudio.
